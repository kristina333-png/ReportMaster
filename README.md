 # ReportMaster 

**Учебный проект **  
Приложение для учёта личных финансов, задач и событий с возможностью экспорта отчётов.

##  Описание проекта

ReportMaster — это десктопное приложение с графическим интерфейсом (WinForms), которое позволяет вести учёт трёх типов записей:
- **Финансы** (доходы/расходы)
- **Задачи** (с отслеживанием статуса и срока)
- **События** (с местом проведения )

###  Основной функционал (MVP)
1. Главное окно с вкладками и DataGridView для каждого типа записей
2. Добавление новых записей через форму
3. Редактирование записей 
4. Удаление записей (кнопка/контекстное меню)
5. Фильтрация по категориям
6. Сохранение данных 
7. Экспорт отфильтрованного списка в CSV/TXT
8. Подсчёт итогов (сумма для финансов, статистика для задач/событий)
9. Разные наборы полей для каждого типа записей
